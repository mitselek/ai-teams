## TLDR

The same discipline -- library-first / canonical-source-first probe before substrate-empirical probes -- recurred three times in ~24 hours at three distinct Layer-1↔Layer-0 substrate-layer-pairs. Each time an operator anchored on a sub-canonical Layer-1 source and a different agent descended to a Layer-0 canonical source and surfaced the substrate-truth gap.

## Key ideas

- **The discipline**: before running substrate-empirical probes, query the canonical-source documentation the substrate's intent is anchored on (FR wiki for internal, substrate-provider API ref for consumer, canonical doc for external adoption).
- **Cheap-first**: library-query is O(seconds); empirical substrate-discovery is O(minutes-to-hours). When library-query collapses the surface, the empirical effort is avoided entirely.
- **n=3 in-session, three layer-pair types**: FR-internal↔FR-wiki (Aen), CF-product-docs↔CF-API-canonical (Brunel), announcement-blog↔Anthropic-canonical-doc (Finn). Layer-pair-type-invariant.
- **Coupling-dimension**: substrate-layer-pair-of-application -- distinct from the cluster's other axes (cross-document, iteration-depth, role-position).
- **Cheap-first applies recursively**: library-query > FR-design read > operational read > runtime read; adds Layer 0 atop the three-layer ladder.
- **Anti-pattern is discriminator-anchored-on-sub-canonical-source** applied to library-first; counters it.
- **Instance 2 ≡ Sub-Instance 4 of sub-shape-e** (same incident, two axes); **Finn = candidate substrate-fit-researcher fourth vantage**.
- **n=3 in-team**; cross-team confirmation is the promotion-to-high gate.
